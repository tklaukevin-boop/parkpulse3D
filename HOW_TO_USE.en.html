How to use ParkPulse on mobile

ParkPulse HK shows a map + bottom sheet in your phone browser: pick an intent tab, browse carparks / meters / EV within 2KM, then open a facility and navigate in Google Maps. No login. In-app languages: 繁 / 简 / EN (this guide matches the EN UI).

01

Open the app (mobile home screen)

On your phone browser, open: https://parkpulsehk.web.app/

  • Header: About, Setup, Locate, languages 繁 / 简 / EN, and Switch to Desktop.
  • Bottom sheet: four intent tabs — AUTO Best, EV Dock, Carpark, Meter; use Expand / Hide.
  • Desktop layout: for the full desktop chrome, tap header Switch to Desktop (this guide stays mobile-first).

Status line example: 2KM Live: 21 Carparks · 88 Meters.

02

Locate / My GPS Origin

The cyan map label My GPS Origin marks your start point. Header Locate re-centers on it. If the browser never allowed location (or you chose Never allow), the app still works with the default / map range and will not force a wide first-run GPS panel.

  • With the sheet collapsed, tap Expand to raise the list.
  • Right-side FABs: Switch to Dark Map, Recenter 2KM.
03

Bottom-sheet intent tabs

After expanding the sheet, use the four tabs to switch recommendations / lists:

AUTO Best EV Dock Carpark Meter
  • Search box: Search 2KM carparks, streets or malls...
  • Tap a list card (e.g. Star Ferry Car Park) to focus the map and open detail.
  • Tap Hide when you want more map.
04

Header & map FABs

Mobile has no separate 2D/3D or layer FABs; 3D buildings are controlled inside Setup (see section 06). On the map’s right edge you mainly get theme and recenter:

  • Switch to Dark Map — day / night map theme.
  • Recenter 2KM — pull the map back to the 2KM range center.
  • Header: About, Setup, Locate, languages, desktop layout.
05

Facility detail

Tap a carpark pillar / label on the map, or a bottom-sheet list card, to open detail (e.g. Star Ferry Car Park): spaces, fees, DC/AC guns.

  • Navigate: tap the navigate control on the card → Navigate (Google Maps).
  • You can still tap Expand on the sheet for more list context.
06

Setup (System Setup & Data Sources)

Tap header Setup to open the modal titled System Setup & Data Sources. Top filters:

All Facilities Available Only Smart Meters (2,989) DC Fast Charge No Queue Jam
All Specs DC Super (≥60kW) AC Med (7-22kW)
  • Data mode: this demo runs Mode A · Live (DATA.GOV.HK).
  • Tap Done to close; settings apply immediately.
  • Scroll further in the modal for sync / map theme / 3D building controls when present.
